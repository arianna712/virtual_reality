# Virtual Reality Modelling - Lab 2

A first-person scene where the player prepares a table for breakfast.

Turn on the lamp, then pick up and place the nine objects in the order shown on screen. There are 19 steps in total. The interface shows the current task, inventory and progress.

Controls:
- WASD: move
- Mouse: look around
- E: interact
- Esc: release the mouse

Open the project in Godot and press F6 with scenes/main.tscn open, or F5 to run the project.

The first-person controller is by Jeh3no. Model, texture and controller sources, credits and license notices are listed in links.txt.

AI assistance: I used AI to help write and debug parts of the code, particularly the guided interaction sequence, inventory handling and on-screen instructions. I reviewed the AI-assisted code and tested the resulting behaviour in Godot, including the interaction order, object placement and completion of the activity. The project also uses an existing first-person controller and external assets, whose sources are listed in links.txt.
